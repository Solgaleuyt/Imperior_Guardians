# 🚀 Atualizações do Projeto (Changelog)

Todas as alterações notáveis deste projeto serão documentadas neste arquivo. O formato é baseado no [Keep a Changelog](https://keepachangelog.com) e este projeto adere ao [Versionamento Semântico](https://semver.org).

---

## - 2026-10-29

### ✨ Adicionado
- **Nova Funcionalidade:** Implementação do modo escuro automático com base nas preferências do sistema.
- Adicionado suporte para múltiplos idiomas (PT-PT, EN-US).
- Integração com a API de notificações em tempo real.

### 🐛 Corrigido
- Correção de um bug crítico onde o botão de envio travava após o primeiro clique.
- Ajuste na responsividade da tabela de dados em dispositivos móveis.
- Resolução de vazamento de memória no componente de paginação.

### ⚡ Melhorado
- Otimização do tempo de carregamento inicial em 35%.
- Atualização das dependências de segurança do projeto.
